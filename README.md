# XuperTV-Linux

**Adaptación comunitaria no oficial de XUPER TV Desktop 1.3.0 para Linux.** Este proyecto adapta a Linux la aplicación de escritorio para Windows (`.exe`), tomando como base el port para webOS [XUPER-HYDRA-PORT-WEBOS](https://github.com/cristianco7/XUPER-HYDRA-PORT-WEBOS ).

Busca facilitar su ejecución en distribuciones Linux mediante una aplicación de escritorio basada en Electron y paquetes para Debian/Ubuntu (`.deb`), Fedora (`.rpm`), Arch Linux (`.pacman`) y otras distribuciones compatibles mediante AppImage.

El repositorio incluye archivos y scripts para compilar y empaquetar la aplicación. Los instaladores disponibles se publican en [Releases](https://github.com/crisdavi2802/XuperTV-Linux/releases ).

Este proyecto no es oficial ni está afiliado a XUPER TV. Se reconoce el trabajo de los autores de los proyectos previos relacionados; la adaptación y el empaquetado para Linux corresponden a este proyecto.
